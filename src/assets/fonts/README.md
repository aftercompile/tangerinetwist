Letter fonts for the server-rendered design thumbnails (`/api/design-image`). These are the
fonts the physical letter pieces are modelled from; the same families are loaded for the
browser via `next/font` in `src/components/letter-builder/fonts.ts`.

- Archivo Black — SIL Open Font License 1.1 (OFL-archivoblack.txt)
